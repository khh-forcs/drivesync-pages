드라이브 동기화

개인정보처리방침

시행일: 2026년 10월 23일

이 방침은 안드로이드 앱 '드라이브 동기화(Drive Sync)'(이하 "앱")가 어떤 정보를 어떻게 다루는지 설명합니다. 앱은 개발자 본인만 쓰는 개인용 앱입니다.

1. 앱이 쓰는 정보

  • 구글 계정 이메일 주소: 어느 계정으로 로그인했는지 앱 화면에 보여 주는 데만 씁니다.
  • 구글 드라이브 파일: 사용자가 동기화 대상으로 고른 드라이브 폴더 안의 파일과 폴더의 이름, 내용, 크기, 수정 시각, 내용 확인 값(MD5)을 읽고 씁니다. 동기화할 폴더를 고르는 화면에서는 드라이브의 폴더 이름 목록을 읽습니다.
  • 휴대폰 파일: 사용자가 고른 휴대폰 폴더 안의 파일을 읽고 씁니다.

앱은 위치, 연락처, 광고 식별자 등 그 밖의 정보를 모으지 않으며, 사용 통계나 분석 도구를 쓰지 않습니다.

2. 구글 드라이브 권한을 쓰는 이유

앱은 구글 드라이브 전체 접근 권한(https://www.googleapis.com/auth/drive)을 요청합니다. 사용자가 앱 밖에서 직접 만든 기존 폴더를 동기화 대상으로 고르고, 그 안의 파일을 내려받고, 고치고, 휴지통으로 옮기려면 이 권한이 필요하기 때문입니다. 앱은 이 권한을 사용자가 고른 폴더를 동기화하는 데만 씁니다.

3. 정보가 오가는 곳

  • 파일은 사용자의 휴대폰과 사용자 본인의 구글 드라이브 사이에서만 오갑니다. 통신은 Google API(googleapis.com)와 암호화된 HTTPS로만 합니다.
  • 개발자가 운영하는 서버는 없으며, 어떤 정보도 개발자나 제3자에게 보내지 않습니다.
  • 정보를 팔거나, 광고에 쓰거나, 사람이 읽게 하지 않습니다.

4. 휴대폰에 저장되는 것과 보관 기간

  • 설정(고른 폴더, 동기화 간격 등), 동기화 기록(파일 경로, 드라이브 파일 ID, 크기, 수정 시각, MD5), 최근 50회의 실행 기록이 앱 내부 저장소에 저장됩니다.
  • 드라이브에서 지워진 파일은 휴대폰의 앱 전용 휴지통에 30일 동안 보관한 뒤 지웁니다.
  • 앱을 삭제하면 위 정보는 모두 휴대폰에서 지워집니다.

5. 권한 철회

구글 계정 관리 → 보안 → '타사 앱 및 서비스 연결'에서 앱의 드라이브 접근 권한을 언제든 끊을 수 있습니다. 휴대폰 설정에서 앱의 파일 접근 권한을 끄거나 앱을 삭제할 수도 있습니다.

6. Google API 서비스 사용자 데이터 정책 준수

앱이 Google API에서 받은 정보를 사용하고 다른 앱으로 전송하는 일은 Google API 서비스 사용자 데이터 정책의 제한적 사용(Limited Use) 요구사항을 포함하여 그 정책을 따릅니다.

Summary in English

Drive Sync is a personal app used only by its developer. It reads the signed-in Google account's email address (to show which account is in use) and reads, writes and trashes files inside the single Google Drive folder the user chooses to sync, using the https://www.googleapis.com/auth/drive scope. Files travel only between the user's phone and the user's own Google Drive over HTTPS to Google APIs. No data is sent to the developer or any third party, sold, used for advertising, or read by humans. Settings and sync records stay on the phone and are deleted when the app is uninstalled. Access can be revoked at any time in the Google Account's security settings.

Drive Sync's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
